# Future Cloudflare MCP adapter

This directory is intentionally **not an MCP server**. It contains a planned
tool contract only. No TypeScript handler, dependencies, Wrangler configuration,
access token, automated deployment or MCP protocol validation is included.

The dataset publisher should be completed and indexed before work begins here.
See `../docs/CLOUDFLARE_MCP_FUTURE.md` for all remaining steps and current
official Cloudflare documentation links.

No `wrangler deploy` command is wired to the GitHub Pages workflow.
