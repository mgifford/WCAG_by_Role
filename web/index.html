Important distinction

WCAG 2.2 success criteria define requirements. ARRM tasks suggest responsibilities. A role filter does not narrow WCAG conformance obligations, establish compliance, or replace manual accessibility testing.

This tool is not an official W3C publication and is not affiliated with W3C.

How this works

Task-level ownership comes from the ARRM task CSV. Primary, secondary and contributor labels describe each role's relationship to a specific task. A separate summary of roles per criterion comes from ARRM's success-criterion responsibility CSV. These are related but not interchangeable: one criterion can have different tasks owned by different roles.

Understanding documents are informative. When available, the unchanged W3C “In Brief” text is included with an explicit source link. The complete Understanding document stays at W3C. Links to WCAG 2.2 point to the normative W3C Recommendation. An unmapped criterion is not an exemption. ARRM's task inventory is not exhaustive.

Known legacy records for the removed success criterion 4.1.1 Parsing are omitted from current results and listed in a downloadable import audit. New or unrecognized criterion IDs are also reported, not silently assigned.
